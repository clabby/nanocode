The package builds one `nanocode` binary from the `nanocode_cli` library: src/main.rs only calls `run()`. `run_with(ModelClients)` lets an embedding binary supply the OpenAI builder, the Claude client and a warm-up future the CLI spawns on its runtime for interactive and exec sessions; they reach `Host::build` through `HostConfig`, and a supplied OpenAI builder replaces `--gateway`. nanocode-machines uses it for MPP-paid models through `nanocode::http` layers. Keep that hook provider-neutral. `nc` is a symlink alias to it (`ln -sf nanocode ~/.cargo/bin/nc`); reload resolves whichever name started the window.

Interactive `/reload` and `/restart` broadcast to the current user's nc windows registered in the native temporary directory, across workspaces and configured session homes. Unix windows stop through runtime shutdown, never explicit turn cancellation, then exec the newest matching program on PATH and resume durable operation IDs. Ephemeral windows report that reload requires durability and remain open.

The reload handoff retains drafts, attachments, queued request IDs, side conversations, focus, settings and executor selection in a private synced file. It also carries each hand the window dialed at runtime through `/runner connect` or the runners tool, with its URL, credential, name, mode and call timeout, captured before runtime shutdown disconnects it; the new window redials every saved hand whose name is not already registered and reports each result as a notice. Hands from `--runner-connect` reconnect through the preserved arguments and accepted listener hands dial back on their own, so neither is saved. Wait for submissions to settle before saving it, preserve durable steer acknowledgements, and do not start queued work during shutdown. Resuming an interrupted tool reports its uncertain outcome instead of replaying dispatched effects. Keep the handoff flag hidden and exclude old positional prompts and prior handoff flags from restart arguments.
