Keep the official provider's tool definitions unchanged. The default Sky provider's catalog is pinned in src/catalog.json as the `tools` array its node_repl returns from MCP tools/list, so its tools and the prompt prefixes built from them are available at session build without starting the provider and stay identical across sessions. Regenerate the file from a live tools/list when the provider changes. Each session starts node_repl on its first call and compares the live catalog with the advertised one; a difference fails the call before anything is dispatched. A missing installation keeps the tools advertised, reports itself through ComputerConfig::unavailable, and fails each call with that error. Configurations built with ComputerConfig::new have no pinned catalog and discover theirs when they connect.

Validate complete Base64 media payloads before accepting them. MIME sniffing needs at most the 12-byte RIFF/WebP header, represented by the first 16 Base64 characters; decode only that prefix after validation.
