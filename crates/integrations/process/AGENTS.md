## grep shim

- `search::install(dir, executable)` links `grep`, `egrep` and `fgrep` to `executable` in `dir/<hash of the executable path>/`; that executable dispatches those argv0 names to `search::run`. `nanocode` installs the shims under `<nanocode home>/shims` for every subcommand, including hands, pointing at the small `nanocode-grep` binary when it is installed beside it: starting the 37 MB CLI cost about 10 ms more per grep than the 410 KB shim under load. Hosts that do not call `install` keep the system grep.
- Every bash, zsh or sh script spawned here starts with `export PATH='<shim dir>':"$PATH";`, so login profiles that rebuild PATH (macOS `path_helper`) cannot reorder it.
- `run` translates the GNU grep command line to ripgrep and execs `rg`: permuted and clustered options, `-NUM`, long options with `=` values, `--include`/`--exclude`/`--exclude-dir` as globs, `-c` with zero counts, stdin when there are no operands and no `-r`, and `--max-depth=0 --threads=1` without `-r`, so directory operands are reported as directories, as grep does, and searches of named files skip rg's thread pool, which widened the tail of concurrent small greps. BRE and ERE patterns are rewritten to Rust regex syntax (escaped groups, alternation, intervals and literal metacharacters swap meaning; bracket expressions keep POSIX backslash and class semantics). Searches add `--hidden` and exclude `.git`, `.svn`, `.hg`, `.bzr`, `.jj` and `.sl`, the directories Claude Code 2.1.283 excludes when it shadows grep with ugrep, and respect ignore files.
- Options with no rg equivalent, backreferences, collating elements and unreadable pattern files run the next real `grep` on PATH with the original arguments, as does any search when `rg` is not installed.
- `output/overnight/grep-compat/run.sh <nc>` compares 64 invocations against GNU grep 3.12; the only expected difference is that `-o` prints empty matches as blank lines.
