Own backend-independent agent handles, lifecycle, session and usage contracts. Keep durability orchestration, subagent registries, provider implementations and native host adapters out of this crate. Preserve the nanocode-agent compatibility reexports and native/WASM future behavior.

Turn::result consumes the turn and drops its private event receiver before awaiting completion. Result-only consumers should use it so unread mirrored events do not accumulate; streaming consumers can continue polling Turn and AgentEvents.

Pending durable turns: a turn left `TurnStatus::Pending` by a retryable failure or a host crash blocks different prompts with a Retry `OperationBlocked` error. List it with `SessionStore::turns(session_id)`. Replay it with `agent.prompt(PromptRequest::new(agent.decode_durable_prompt(turn.input)?).request_id(turn.id))`, which resumes the recorded operation and reports interrupted tool calls as unknown outcomes instead of repeating them. Abandon it by adding `.cancel_on_admission()`, which records the operation Cancelled without a model request. `Turn::cancel` and `cancel_active_turn` only target a live turn and cannot settle an operation pending from a failed attempt or an earlier process.
