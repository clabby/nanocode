Own the lock-free coordination primitives that replace Mutex and RwLock across the workspace. Every primitive is built from arc-swap, atomics, Tokio oneshot and unbounded channels and compiles for native and WASM targets.

Atom holds a value published through arc-swap and changed copy-on-write: update clones the current value, applies the change and retries the compare-and-swap until it lands, so the change closure must be free of side effects and may run more than once; perform sends, wakeups and logging with its returned value after it commits. try_update skips the store when the closure returns None and modify when it returns an error, so a change may edit its private copy freely before failing. Signal is a one-shot event: fire wakes every current and future waiter. Slot holds at most one owned value; put and take swap it atomically, and values are never read in place so take always recovers ownership. Inbox is a multi-producer list built as an Arc-linked stack: push is a compare-and-swap, drain takes every value in push order and any inspects without consuming. SingleFlight runs one future per concurrent burst: the first caller leads, later callers wait for its result, a cancelled leader hands the flight to the next caller, and finished flights clear so the next call starts fresh. Sequencer admits one Turn at a time in arrival order: enter queues a ticket in an Atom and parks on a Signal until the previous Turn drops and hands over, try_enter succeeds only when nobody holds or waits, and a cancelled enter leaves the queue or passes an admission it already received to the next ticket. Owned keeps a value in a Slot behind a Sequencer: acquire moves the value out to the admitted caller as Held, or Leased for acquire_owned on an Arc, and dropping it puts the value back before the next Turn starts, so the value has exactly one owner and no guard aliases it. Actor owns a state value on its own task and runs jobs against it one at a time in the order run was called, since run enqueues before returning its future; a job whose caller drops its future is cancelled, as dropping a lock guard would cancel a critical section, and spawning requires a Tokio runtime on native targets or an installed platform host on WASM.

Prefer Atom or read-mostly ArcSwap values replaced copy-on-write for registries, caches and small state machines, Slot for take-once handoffs, SingleFlight for refresh and reinitialization gates, Actor when an exclusive resource can move onto its own task, and Sequencer or Owned only where a protocol requires one caller at a time across awaits, such as turn admission or a conversation owned by the running turn.
